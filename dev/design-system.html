Creative north star: the personal instrument panel

The chassis is deliberately neutral so the user's own choices give each install its character. Structure — panels, layered elevation, one accent colour, a softly-cornered search pill — stays constant; wallpaper, accent colour and clock typeface change per user. The system's job is to stay legible and out of the way, the way an instrument panel's layout doesn't change even though the view out of the window does.

Key characteristics
  • One user-chosen accent colour, used sparingly, never as a background
  • Elevation tracks real stacking order: cards → dropdowns → modals → overlays
  • Blur only on surfaces that genuinely float over the wallpaper, never stacked
  • Two themes (dark default, light) sharing one token set
  • Every visual cue answers "what is this, and is it above or below me"

Colours

Near-monochrome at rest: one neutral surface family plus a single user-chosen accent. There is no secondary brand colour — the accent is the only colour decision an install makes.

Text and borders

Board surfaces

Board cards tint themselves from --board-rgb and --board-opacity. Text ink on a board is computed for contrast against the card's real backdrop, including the wallpaper behind a translucent card.

Status

The One Signal Rule. The accent appears on focus states, hover borders, primary actions and active toggles — never as a page background, a card fill or body text.

Scoped exceptions

Three surfaces may leave the token set. Each is documented, and the list is closed.

Command palette (light theme)

Cool-slate ink instead of alpha-on-white neutrals, because the palette floats above an arbitrary page: #0f172a, #475569, #64748b, #cbd5e1, #f1f5f9.

Focus timer

A blackout overlay that ignores theme and accent so a session looks identical everywhere: #000 ground, flip face #151618, seams #292a2d / #25262a, viewport-relative corners.

Toolbar popup

A fixed-width shell with a 12px outer corner sized for the browser's popup frame. It mirrors the page tokens through its own theme function, including a readable accent ink.

Typography

Interface: Inter, with eight bundled alternatives via --font-app. Clock: ten faces via --clock-font, the one typographic choice exposed to users. Mono: --font-mono for keyboard chips and literal input only. All bundled fonts are SIL Open Font License, except Roboto Slab (Apache 2.0).

No near-duplicate steps. Don't let 2–3 font sizes cluster within a few pixels on one surface. Pick fewer steps with real contrast (≥1.25×).

Shape & spacing

Four radius steps, no sharp corners. Borders are hairline and strengthen only on hover, focus or accent states.

Spacing scale

UI chrome sits in the 4–16px range; section gaps use 20px and above. Spacing and type scale together through --ui-scale.

Elevation

Structural, not decorative. Shadows share one accent-tinted colour with a tight contact layer plus a soft ambient one, so depth reads as a single light source. Settings uses flat fills and borders instead.

The Stack-Tells-The-Truth Rule. A component's shadow step must match its real interaction layer.

Wallpaper legibility

Text on a photo or video uses a shadow driven by --wp-shadow-opacity, --wp-shadow-blur and --wp-shadow-rgb. It is functional, and off in solid-colour mode.

Motion & layering

Duration and easing

One easing curve for everything that enters or settles. Page switches fade a pre-blurred wallpaper layer instead of re-blurring the image.

Z-index scale

Layout

A single-page shell: fixed top bar, centred clock and search pill, a board grid, and side sheets that overlay rather than push content. There are no marketing-style breakpoints; --ui-scale steps 1 → 1.12 → 1.3 → 1.55 → 1.8 at 1800px, 2200px, 2800px and 3400px, multiplying spacing and type together. Board columns and gutters derive from --boards-gutter so margins stay equal at any size.

Buttons use --r-sm, an accent fill with accent-contrast text and a neutral shadow. focus-visible always draws a 2px accent outline at 2px offset — the one hard accessibility invariant. The search pill promotes its border to the accent on hover or focus. Board cards use --r-lg, e1 at rest, and a border from their own tint. Inputs sit a radius step tighter than buttons, and placeholders always use --text-dim at full opacity.

Do & don't

Do
  • Let accent and wallpaper be the only strongly personalised choices.
  • Match the shadow step to the real stacking order.
  • Keep the clock as the one surface with a user-selectable font.
  • Use neutral elevation shadows — depth means layer, not brand.
  • Compute ink against the real backdrop whenever a surface is translucent.
  • Gate wallpaper text-shadow to wallpaper mode only.
  • Use tokens for radius, spacing, type and timing.
Don't
  • Introduce a second brand or accent colour.
  • Use a coloured or glowing shadow on a button or card.
  • Cluster several font sizes within a few pixels on one surface.
  • Stack a blurred panel on top of another blurred panel.
  • Ship an <img> with an empty src.
  • Re-blur a full-screen image on every view change when opacity can do the work.
